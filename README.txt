BE STRONGER NUTRITION V2

Version orientée coaching sportif / éducation alimentaire.

Cette version :
- ne calcule plus de calories ou macros personnalisées ;
- ne présente pas le contenu comme un bilan diététique ;
- affiche un planning d'idées de repas comme support de coaching ;
- conserve le suivi du poids, tour de taille, énergie, faim, sommeil et adhérence ;
- rappelle les limites de l'outil et l'orientation vers un médecin/diététicien lorsque nécessaire ;
- stocke les données localement sur l'appareil dans cette version.

Important : cette interface ne constitue pas un avis juridique. Avant une commercialisation ou un déploiement auprès de clients, fais valider le périmètre exact de tes prestations par un professionnel compétent en droit de la santé / réglementation française.
